# PRD: 씬바이미 (Scene by Me)

## 한 줄 소개

흘려 쓴 메모가 쌓이면 AI가 상황을 엮어, 평범한 나의 일상을 한 편의 각본과 영화로 만들어주는 서비스.

## 핵심 원칙

- 사용자가 하는 일은 **메모뿐**이다. 형식, 길이, 문체를 강요하지 않는다.
- AI가 하는 일은 **엮어서 작품으로 키우기**다.
- 기록이 쌓일수록 이야기가 자란다. 각본은 고정된 결과물이 아니라 계속 갱신된다.

## 대상 사용자

- 1차: 자기 삶을 이야기로 남기고 싶은 일반인
- 확장: 배우(역할 자서전), 영화감독·작가(아이디어 메모 및 맥락 관리)

## 기능 요구사항 (PoC)

| # | 기능 | 설명 |
|---|---|---|
| F1 | 메모 | 채팅창에 일화, 대화, 생각을 자유롭게 입력. 한 줄 가능. TXT·PDF 업로드 지원 |
| F2 | 상황 추출 | 메모에서 인물, 장소, 시기, 감정, 사건을 추출해 누적 저장 |
| F3 | 문체 학습 | 메모 길이, 말투(반말/존댓말), 자주 쓰는 표현을 분석해 문체 프로필 생성 |
| F4 | 맥락 엮기 | 새 메모를 기존 기록과 비교해 이어지는 상황, 반복 인물, 테마를 이야기 줄기로 묶음 |
| F5 | 장면화 | 엮인 상황을 씬 헤딩·지문·대사가 있는 시나리오 장면으로 재구성 |
| F6 | 서사 성장 | 기록이 쌓이면 장면을 막(Act) 단위로 확장. 복선, 전환점, 주제를 찾아 각본 전체 갱신 |
| F7 | 감상·출력 | 현재까지의 각본을 읽기 화면으로 제공. Markdown 내보내기, 인쇄용 화면으로 PDF 저장 |

## 3일 규칙

- **서로 다른 날짜(Asia/Seoul 기준) 3일 이상** 메모가 있어야 첫 장면이 생성된다.
- 이유: 장면으로 엮을 만큼의 맥락 확보 + 사용자 문체·습관 파악 + 최소 3일 지속 사용 유도
- 3일 이전에는 "이야기가 모이는 중" 상태를 보여준다.
  - 지금까지 등장한 인물, 장소, 감지된 감정
  - 예고편 한 줄 (AI가 만든 로그라인 형태의 짧은 문장)
  - 첫 장면까지 남은 일수

## 이용 흐름

메모(최소 3일) → 첫 장면 확인 → 계속 메모 → 이야기가 자라는 과정 감상 → 나만의 각본 완성

## 화면 (PoC)

1. **메모 화면**: 채팅 형태. 입력창, 파일 업로드 버튼, 기록 목록
2. **상태 패널**: 기록 일수, 3일 진행도, 등장 인물·테마 미리보기
3. **각본 화면**: 막 → 장면 순으로 각본 표시, 각 장면의 출처 메모 확인 가능
4. **내보내기**: Markdown 다운로드, 인쇄용 화면

## PoC 범위 밖 (하지 않음)

- 회원가입, 로그인, 다중 사용자 (PoC는 로컬 단일 사용자)
- 클라우드 배포
- 배우 모드, 공동 각본
- 인문학 작품 연결 기능

## 개인정보 원칙

- 모든 데이터는 로컬 `data/` 폴더에만 저장
- 외부 API로 사용자 메모를 보내지 않음 (로컬 LLM만 사용)

## 성공 지표 (PoC 검증용)

- 3일 이상 기록한 사용자 비율
- 첫 장면 확인 후 추가 메모 작성 여부
- 장면이 "내 이야기 같다"는 주관 만족도 (5점 척도)
